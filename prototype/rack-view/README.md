# 機櫃圖雛型（智慧網路管理平臺 › 有線設備 › 網路圖）

在既有「網路圖」功能的「地圖」「3D」旁新增「機櫃圖」頁籤，把網管小學堂的機架、設備面板、埠、燈號、網路線等元素用在真實設備上。本目錄是純前端雛型（單一 HTML、無框架、示意資料），供討論操作體驗與資料對應。

- 操作體驗：開啟 `index.html`，或見發布版（私人連結，需分享後他人才能開）。
- 資料全為示意，不連任何系統。

## 需求對照

| 需求 | 雛型中的做法 |
|---|---|
| 1. 地圖旁增加「機櫃圖」頁籤 | 頂部頁籤列：地圖 / 3D / 機櫃圖。路由建議 `devices/network-map/rack`，與現有 `devices/network-map/map`、`/3d` 並列 |
| 2. 結合網管小學堂元素，呈現真實燈號與接線 | 機架（含 U 標尺）、金屬面板、RJ45 / SFP 埠、Link / Act 燈、PWR 燈、UTP / 光纖線。燈號由設備與埠狀態決定，線由 LLDP 連線與手動標記構成 |
| 3. 設備順序可上下移動 | 拖曳設備、右欄 ▲▼ 按鈕、鍵盤方向鍵三種方式；順序即時存檔並提示將呼叫的 API |
| 4. 與網路圖對應 | 右欄「網路圖對應」小圖與機櫃圖共用選取狀態；「在地圖上顯示」切回地圖並圈出機櫃；地圖上的機櫃圓點可直接開機櫃圖；跨機櫃連線以幹線標籤呈現，一鍵跳到對端 |

## 風格來源

- 平臺殼層（頂欄、側欄選單、麵包屑、subheader、panel、nav-tabs、按鈕、badge、表格、toast）依自研「智慧網路管理平臺」的實際前端撰寫：SmartAdmin 5 / Bootstrap 5.3 的 class 命名與結構，變數值（主色 `#886ab5`、success `#1dc9b7`、warning `#ffc241`、danger `#fd3995`、文字 `#505050`、Public Sans 字型、panel 陰影與漸層標頭）取自平臺編譯後的 CSS。平臺為淺色單一主題，雛型亦然。
- 機櫃圖內的機架、設備面板、埠、燈號、網路線沿用網管小學堂的 SVG 元件與色票。
- 雛型為單一 HTML，樣式內嵌；整合進平臺時殼層部分直接改用既有的 Bootstrap / SmartAdmin class，機櫃圖部分抽成 React 元件即可。

## 視覺規則（沿用網管小學堂）

- 設備面板：深色金屬、兩側耳片與螺絲、左側名稱與 IP、右上 PWR 燈。配線架用淺色面板與黃色標籤貼紙，表示被動設備。
- PWR 燈：綠＝正常、橘＝警告、紅閃＝離線。離線設備面板外框變紅、埠燈全滅。
- 埠：RJ45 黑色插孔；PoE 埠橘框；SFP 黃框，裝了模組才有顏色（黃＝單模、青＝多模）。
- 埠燈：Link 綠；協商到 100 Mbps 轉橘；近期有流量 Act 黃閃；對端中斷紅閃。
- 網路線：UTP 藍、單模光纖黃、多模光纖青；手動標記的連線為虛線；中斷變紅色虛線；選取時加粗，其餘淡化。
- 跨機櫃或對外的連線不畫到另一座機櫃，改畫到機架上方的「幹線標籤」，標籤寫明對端機櫃、設備與埠，點了直接跳過去。

## 資料對應（平臺現有路由）

| 元素 | 來源 | 備注 |
|---|---|---|
| 機櫃與所屬建築 | `network-maps/{map}/buildings`、`units.show` | 一座建築可有多座機櫃 |
| 機櫃內設備 | `devices/list` | 篩選單位內有線、機架式類型；U 數依型號查表，配線架等被動設備由管理者手動加入 |
| 設備狀態 | `topology/status`、`assistant.tools.device-health` | up / warn / down |
| 埠與埠狀態 | `devices/{device}/ports`、`port-metrics` | ifOperStatus、速率、流量、PoE、VLAN |
| 網路線 | `topology/structure`、`topology/manual-relations` | LLDP / CDP 自動發現為實線，手動標記為虛線 |
| 地圖對應 | `network-maps/{map}/placements` | 機櫃綁定建築座標，選取狀態跨頁籤共用 |

### 需新增

| 項目 | 建議 | 說明 |
|---|---|---|
| 機櫃 | `network-maps/{map}/racks` CRUD | 名稱、建築／樓層、總 U 數、地圖座標 |
| 設備在機櫃中的位置 | `POST network-maps/racks/{rack}/devices/{device}/slot` `{ u_top, height_u }`；`DELETE` 移出 | 比照現有 `placement.store` / `placement.destroy` |
| 配線架對端標示 | 擴充 `devices.ports.update` 的備注欄位，或獨立配線表 | 讓埠一覽能顯示「教室 201 前」這類實體位置 |

## 雛型未涵蓋、待討論

- 權限：單位／學校管理者可排序與排入；中心視角是否唯讀。
- 多座機櫃並排顯示（同一機房兩座櫃）與機櫃背面視圖。
- 設備 U 數來源：型號對照表維護方式；未知型號預設 1U 並允許手動改。
- 即時更新頻率：埠燈號建議沿用現有輪詢或 WebSocket 機制，避免每 5 秒全量重抓。
- 線材種類（UTP / 單模 / 多模）無法自動得知，需由 SFP 模組類型推斷或手動標記。
- 列印配線表（設備、U 位、埠、對端）的格式。
